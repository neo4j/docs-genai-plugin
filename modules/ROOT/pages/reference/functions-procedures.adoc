== ai.text.completion()
|===
|    *Syntax*        3+| `ai.text.completion(prompt, provider, configuration) :: STRING`
|    *Description*   3+| Function to return generated text output based on the provided prompt.
.4+| *Input arguments* | *Name*          | *Type*   | *Description*
|                        `prompt`        | `STRING` | Textual prompt.
|                        `provider`      | `STRING` | Name of the third party AI provider, see xref:generate-text.adoc#providers[Generate text -> Providers].
