[[generate-once]]
[role=label--new-2025.11]
== Generate text from prompt

The function `ai.text.completion` can be used to generate text based on a text prompt.
It is similar to submitting a prompt to an LLM.

[NOTE]
Use `CALL ai.text.completion.providers()` (see xref:reference/functions-procedures.adoc#ai-text-completion-providers[reference]) to see supported providers and their configuration options.

[role=label--function label--new-2025.11]
[cols="1,1,1,3"]
.Signature for `ai.text.completion`
|===
|    *Syntax*        3+| `ai.text.completion(prompt, provider, configuration) :: STRING`
|    *Description*   3+| Generate text output based on the provided prompt.
.4+| *Inputs* | *Name*          | *Type*   | *Description*
|                        `prompt`        | `STRING` | Textual prompt.
|                        `provider`      | `STRING` | Name of the third party AI provider, see xref:#providers[Providers].
|                        `configuration` | `MAP`    | Provider specific configuration, see xref:#providers[Providers].
2+| *Returns*                            | `STRING` | Generated text based on the provided prompt.
|===

[.tabbed-example]
====
[.include-with-OpenAI]
======
The example below selects the 5 top-rated movies, joins their titles and plots into a single, newline-separated string, and asks the external AI provider to pick the most child-friendly one.

[source, cypher, test-result-skip]
----
MATCH (n:Movie) WHERE n.imdbRating IS NOT NULL
ORDER BY n.imdbRating DESC LIMIT 50  // <.>
WITH n.title + ': ' + n.plot AS movie  // <.>
WITH
  reduce(acc = '', item IN collect(movie) | acc + item + '\n') AS movies,  // <.>
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: {
      instructions: 'Be short.'
    }
  } AS config  // <.>
RETURN ai.text.completion(
  'Here is a list of movies with their titles and plots. Recommend the most child-friendly one.\n\n' + movies,  // <.>
  'openai',
  config
) AS result
----

<.> Pick the 50 top-rated movies.
<.> Join title and plot as `<title>: <plot>`.
<.> Join all movies into a single, newline-separated string.
<.> Provider specific configuration, see xref:#providers-openai[Providers -> OpenAI].
<.> Prompt for the AI model.

[role="queryresult",options="header",cols="1"]
|===

| result
| "Cosmos. It’s an educational, non-graphic science documentary about the universe, making it the most child-friendly option here (parental guidance for younger kids)."

|===

[[aggregate-completion]]
== Generate text for multiple values

The function `ai.text.aggregateCompletion` can be used to generate text for multiple inputs based on a text prompt.
It is similar to submitting the same prompt to an LLM for each of the provided values.

[role=label--function label--new-2026.03]
[cols="1,1,1,3"]
.Signature for `ai.text.aggregateCompletion`
|===
|    *Syntax*        3+| `ai.text.aggregateCompletion(value, prompt, provider, configuration = {}) :: STRING`
|    *Description*   3+| Aggregating function that generates text from the specified prompt across grouped rows.
.5+| *Input arguments* | *Name*          | *Type*   | *Description*
|                        `value`         | `STRING` | The value to aggregate over.
|                        `prompt`        | `STRING` | The prompt to generate text from.
|                        `provider`      | `STRING` | The identifier of the provider: 'Azure-OpenAI', 'Bedrock', 'Bedrock-Nova', 'Bedrock-Titan', 'OpenAI', 'VertexAI'.
|                        `configuration` | `MAP`    | Provider specific configuration, use `CALL ai.text.structuredCompletion.providers()` to find the configuration needed for each provider. You can specify additional vendor options by adding `vendorOptions` with a map of values that will be passed along in the request.
2+| *Returns*                            | `STRING` | Generated text based on the provided prompt.
|===

[.tabbed-example]
====
[.include-with-OpenAI]
======

The example below aggregates product descriptions per product category and asks the external AI provider to summarize the key themes into a short bullet pointed list.

[source, cypher, test-result-skip]
----
MATCH (p:Product)
WITH p, {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config
RETURN p.category AS category,
       ai.text.aggregateCompletion(
         p.description,  // <.>
         'Summarize the key themes in these product descriptions as a short bullet list.',
         'openai',
         config
       ) AS category_summary  // <.>
ORDER BY category;
----

<.> The `value` argument indicates the expression being aggregated (such as a column varying within the group).
It must be of type `STRING` -- use Cypher's link:https://neo4j.com/docs/cypher-manual/current/functions/string/#functions-tostring[`toString()`] function to convert non-string values.
<.> The function produces a single `STRING` per group.

| "Books" | "- Imaginative storytelling\n- Strong character development\n- Themes of friendship and adventure"
| "Electronics" | "- Battery life and fast charging\n- Camera quality\n- Value for money"

== Chat with context

The function `ai.text.chat` allows you to exchange several messages with an LLM, as part of a single thread.

[NOTE]
Chats are only supported with OpenAI and Azure-OpenAI.
Use `CALL ai.text.chat.providers()` (see xref:reference/functions-procedures.adoc#ai-text-chat-providers[reference]) to see supported providers and their configuration options.

[role=label--function label--new-2025.12]
[cols="1,1,1,3"]
.Signature for `ai.text.chat`
|===
|    *Syntax*        3+| `ai.text.chat(prompt, chatId, provider, configuration = {}) :: MAP`
|    *Description*   3+| Chat based on the specified prompt, optionally continuing a previous interaction.
.5+| *Inputs* | *Name* | *Type* | *Description*
| `prompt` | `STRING` | The user message to send.
| `chatId` | `STRING` | Previous chat ID to continue the conversation. If this is the first message in the conversation, set it to `null`.
| `provider` | `STRING` | The identifier of the provider: `'azure-openai'`, `'openai'`. See xref:#providers[Providers].
| `configuration` | `MAP` | Provider-specific options. See xref:#providers[Providers].
2+| *Returns*     | `MAP` | Contains `message`, with the response text, and `chatId` for follow-up messages.
|===

=== Continue a chat using an existing chat ID

[NOTE]
The returned chat ID is different for every call, so you need to update it at every request if you want the model to always have the context of the whole chat.
Each request allows you to spawn a new thread by forking the interaction with the context provided up until that point.

[WARNING]
Even if chat IDs are scoped to the API token that generated them, treat them as sensitive information, as further messages might ask to reveal previously-provided information (ex. `What was my initial request?`).

[[web-access]]
== Allow models to access the web

Some models visit URLs if prompted to do so, but not all do.
OpenAI requires the `tools` list to include `web_search`, provided via `vendorOptions`.

[source, cypher]
----
RETURN ai.text.completion(
  'Summarize https://en.wikipedia.org/wiki/Neo4j',
  'OpenAI',
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: {
      tools: [{
        type: 'web_search'
      }]
    }
  }
)
----


[[parallel-requests]]
== Run multiple requests in parallel

To run text completion for several prompts in parallel, you have two options:

1. Use link:https://neo4j.com/docs/cypher-manual/current/subqueries/subqueries-in-transactions/#concurrent-transactions[`CALL {...} IN CONCURRENT TRANSACTIONS`], with 1 row per transaction: +
+
[source, cypher]
----
WITH ['Name a movie', 'Name a book'] AS prompts
UNWIND prompts AS prompt
CALL(prompt) {
  WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config
  RETURN ai.text.completion(prompt, 'openai', config) AS response
} IN CONCURRENT TRANSACTIONS OF 1 ROW
RETURN response
----
+
2. Use link:https://neo4j.com/docs/cypher-manual/current/planning-and-tuning/runtimes/concepts/#runtimes-parallel-runtime[Cypher's parallel runtime]: label:enterprise-edition[] +
+
[source, cypher]
----
CYPHER runtime=parallel
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano'
  } AS config,
  ['Name a movie', 'Name a book'] AS prompts
UNWIND prompts AS prompt
RETURN ai.text.completion(prompt, 'openai', config) AS result
----


[[providers]]
== Providers

You can generate text via the following providers:

- OpenAI (`openai`)
- Azure OpenAI (`azure-openai`)
- Google Vertex AI (`vertexai`)
- Amazon Bedrock Nova Models (`bedrock-nova`)


[[providers-openai]]
=== OpenAI

.OpenAI parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*          | *Type*      | *Default* | *Description*
| `model`         | `STRING`    | -         | Model ID (see https://platform.openai.com/docs/models[OpenAI -> Models]).
| `token`         | `STRING`    | -         | OpenAI API key (see https://platform.openai.com/api-keys[OpenAI -> API Keys]).
| `chatHistory`   | `LIST<ANY>` | `[]`      a| Optional conversation history to provide context to the model. Pass a list of `MAP` values with structure:

- `role`: either `user` or `assistant`
- `content`: a `STRING` representing a message
| `vendorOptions` | `MAP`       | `{}`      | Optional vendor options that will be passed on as-is in the request to OpenAI (see https://platform.openai.com/docs/api-reference/responses/create[OpenAI -> Create a model response]).
|===

.Usage example
[source, cypher]
----
WITH
  {
    token: $openaiToken,
    model: 'gpt-5-nano',
    vendorOptions: {
      instructions: 'Be short.'
    },
    chatHistory: [
      {
        role: "user",
        content: "My favorite movies are in the Fantasy or Sci-fi genre."
      },
      {
        role: "assistant",
        content: "Nice! fantasy and sci-fi have great vibes. Want tailored recs?"
      }
    ]
  } AS conf
RETURN ai.text.completion('Yes, please recommend a movie to me', 'openai', conf) AS result
----

[NOTE]
You can change OpenAI's base URL (default: https://api.openai.com) via the `genai.openai.baseurl` setting.
The change applies to all `ai.text.*` calls that use OpenAI.
See xref:reference/config.adoc#config-genai.openai.baseurl[Configuration settings -> genai.openai.baseurl].
