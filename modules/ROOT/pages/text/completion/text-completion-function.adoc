= ai.text.complete

This function is used to generate text based on a provided prompt using third party AI providers.

.Details
|===
|    *Syntax*        3+| `ai.text.complete(prompt, provider, configuration) :: STRING`
|    *Description*   3+| Function to return generated text output based on the provided prompt.
.4+| *Input arguments* | *Name*          | *Type*   | *Description*
|                        `prompt`        | `STRING` | Textual prompt.
|                        `provider`      | `STRING` | Name of the third party AI provider, see <providers section>.
|                        `configuration` | `MAP`    | Provider specific configuration, see <providers section>.
| *Returns*          3+| Generated text based on the provided prompt.
|===

== Providers

The function currently supports the following providers:

- OpenAI (`openai`)
- Google Vertex AI (`vertexai`)
- Amazon Bedrock Nova Models (`bedrock-nova`)

You can use query `CALL ai.text.completion.providers()` to retrieve a list of the providers supported in your database.

=== OpenAI

.OpenAI configuration parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*          | *Type*   | *Default* | *Description*
| `model`         | `STRING` | -         | Model id (see https://platform.openai.com/docs/models).
| `token`         | `STRING` | -         | OpenAI API key (see https://platform.openai.com/api-keys).
| `vendorOptions` | `MAP`    | `{}`      | Optional vendor options that will be passed on as-is in the request to Open AI (see https://platform.openai.com/docs/api-reference/responses/create).
|===

==== Usage example

.Query
[source, cypher, indent=0]
----
WITH
  {
    token: $openAiApiKey,
    model: 'gpt-5-nano',
    vendorOptions: {
      max_output_tokens: 1024,
      instructions: 'Be short.'
    }
  } AS conf
RETURN ai.text.complete('Name a movie', 'openai', conf) AS result
----

.Result
[role="queryresult",options="header,footer",cols="1*<m"]
|===

| result
| "2001: A Space Odyssey"
1+d|Rows: 1

|===

=== Google Vertex AI

.Vertex configuration parameters
[opts=header, cols="1,1,1,3"]
|===
| *Name*          | *Type*   | *Default* | *Description*
| `model`         | `STRING` | -         | Model resource name (see https://console.cloud.google.com/vertex-ai/model-garden).
| `project`       | `STRING` | -         | Google cloud project ID.
| `region`        | `STRING` | -         | Google cloud region (see https://cloud.google.com/vertex-ai/docs/general/locations).
| `publisher`     | `STRING` | 'google'  | Model publisher.
| `token`         | `STRING` | -         | Vertex API access token.
| `vendorOptions` | `MAP`    | `{}`      | Optional vendor options that will be passed on as-is in the request to Vertex (see https://cloud.google.com/vertex-ai/docs/reference/rest/v1/projects.locations.endpoints/generateContent).
|===

==== Usage example

.Query
[source, cypher, indent=0]
----
WITH
  {
    token: $vertexApiAccessKey,
    model: 'gemini-2.5-flash-lite',
    publisher: 'google',
    project: 'my-google-cloud-project',
    region: 'asia-northeast1',
    vendorOptions: {
      labels: { someLabel: 'bla' },
      systemInstruction: 'Be short.'
    }
  } AS conf
RETURN ai.text.complete('Name a movie', 'vertexai', conf) AS result
----

.Result
[role="queryresult",options="header,footer",cols="1*<m"]
|===

| result
| "2001: A Space Odyssey"
1+d|Rows: 1

|===

[[amazon-bedrock-nova]]
=== Amazon Bedrock Nova Models

This provider gives support for all models that uses the same request parameters and response fields as the Nova text models.

.Amazon Bedrock Nova Configuration
[opts=header, cols="1,1,1,3"]
|===
| *Name*            | *Type*   | *Default* | *Description*
| `model`           | `STRING` | -         | Model ID or its ARN.
| `region`          | `STRING` | -         | Amazon region (see https://docs.aws.amazon.com/bedrock/latest/userguide/models-regions.html).
| `accessKeyId`     | `STRING` | -         | Amazon access key id.
| `secretAccessKey` | `STRING` | -         | Amazon secret access key.
| `vendorOptions`   | `MAP`    | `{}`      | Optional vendor options that will be passed on as-is in the request to Bedrock (see https://docs.aws.amazon.com/bedrock/latest/userguide/model-parameters.html).
|===

==== Usage example

.Query
[source, cypher, indent=0]
----
WITH
  {
    accessKeyId: $awsAccessKeyId,
    secretAccessKey: $secretAccessKey,
    model: 'amazon.nova-micro-v1:0',
    region: 'eu-west-2',
    vendorOptions: {
      system: [{ text: 'Be short' }],
      inferenceConfig: { maxTokens: 1024 }
    }
  } AS conf
RETURN ai.text.complete('Name a movie', 'bedrock-nova', conf) AS result
----

.Result
[role="queryresult",options="header,footer",cols="1*<m"]
|===

| result
| "2001: A Space Odyssey"
1+d|Rows: 1

|===

=== Amazon Bedrock Titan Models

This provider gives support for all models that uses the same request parameters and response fields as the Titan text models.

Configuration and usage is similar to xref:#amazon-bedrock-nova[ai.text.completion].
